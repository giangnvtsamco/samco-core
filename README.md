# samco-core · v1.0

Bộ dùng chung cho mọi app SAMCO (VinFast SAMCO Bình Tân).

| File | Nội dung |
|---|---|
| `style.css` | Màu, chữ, nút, thẻ, bảng, tab, chế độ tối |
| `api.js` | Hàm `call(fn, ...args)` gọi Apps Script |
| `ui.js` | Thông báo, định dạng tiền/ngày, `esc`, bỏ dấu, thu nhỏ ảnh |

Các app nạp từ `https://giangnvtsamco.github.io/samco-core/…`. Sửa ở đây thì mọi app đổi theo.
